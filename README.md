# Matrix

Gotove verzije Matrixa za Mac (Apple Silicon i Intel). Kod je privatan, ovdje su samo instalacije.

## Instalacija

1. Skini zadnji `Matrix_<verzija>_universal.dmg` iz [Releases](https://github.com/MJuici/matrix-releases/releases/latest).
2. Otvori dmg i povuci Matrix u Applications.
3. Prvo otvaranje: macOS javi da ne može provjeriti app. Otvori System Settings > Privacy & Security, skroz dolje klikni **Open Anyway** i potvrdi. To je samo prvi put.
4. Matrix pokreće Claude Code i Codex koje već imaš. Instaliraj barem jednog i jednom se prijavi u Terminalu (`claude`, `codex`).

## Ažuriranje

Matrix sam provjeri ima li nove verzije, skine je, provjeri potpis i ponudi Restart.
